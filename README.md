# ATM Simulator

An educational ATM simulator written in Lua.

## Features

- Deposit money
- Withdraw money
- Check account balance
- Validate operations
- Logging of transactions

## Project Structure

BankAPI.lua   - banking logic
Logger.lua    - logging module
main.lua      - application entry point

## How to Run

1. Install Lua 5.4
2. Clone the repository
3. Run

lua main.lua

## Example

Deposit: 1000
Withdraw: 300
Balance: 700
